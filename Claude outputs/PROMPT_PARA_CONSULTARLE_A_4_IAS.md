# CONSULTA MAESTRO: Manual de Consultoría EJECUTABLE y DENSO

## CONTEXTO

Soy dueño de **E&T (Estrategia y Talento)**, consultora de recursos humanos y organizacional en Perú. Tengo 7 unidades de servicio y ~25 servicios individuales.

Acabo de crear una **estructura universal** para documentar CÓMO ejecutar cada servicio. El objetivo es que cualquier consultor (incluyendo yo) pueda abrir el manual, leer una línea, y saber EXACTAMENTE qué hacer, sin necesidad de interpretación ni creatividad.

---

## LO QUE TENGO AHORA

### La Estructura Universal (Aplica a TODO servicio):

**4 FASES DE EJECUCIÓN:**
1. **PRE-SERVICIO** — Diagnóstico, contexto, confirmación (email + llamada)
2. **EJECUCIÓN PRINCIPAL** — El trabajo real (talleres, sesiones, análisis)
3. **POST-SERVICIO** — Reporte, presentación, validación
4. **CIERRE COMERCIAL** — Firma, pago, siguiente paso

### Un Ejemplo Completo:

**U1 Servicio 1: Diagnóstico Organizacional Express** (completamente documentado)

Cada actividad contiene:
- ⏱ Duración exacta
- 👥 Participantes específicos
- 🎯 **SCRIPT EXACTO** (palabra por palabra qué decir)
- ➜ **DECISIONES** (Si cliente dice A → Responde B)
- 🚩 **SEÑALES CRÍTICAS** (Qué escuchar, qué significa cada respuesta)
- 📋 **ENTREGABLES** (Qué queda después)

### Ejemplo de Script (estilo):
```
TÚ (MIN 0): "Buenos días. [Mirada a cada uno]. Hoy hacemos un viaje rápido."
[PAUSA 3 seg]
TÚ: "Olviden cómo hacen las cosas hoy. Piensen como si fuera el PRIMER DÍA del año que viene."
[ESCRIBIR EN PIZARRA: "AÑO PASADO (2025) vs. AÑO QUE VIENE (2026)"]
TÚ: "¿Cuál fue tu 1 objetivo empresarial el año pasado?" 
[ESPERA GERENTE, REPITE LO QUE DIJO]

Si cliente dice: "No sé, fue mucho" 
→ Responde: "Exacto, ahí está el problema. Es lo que vamos a resolver hoy."

Si cliente dice: "Crecimiento de ingresos 30%"
→ Responde: "Perfecto. ¿Lo lograste? ¿En qué %?"
```
